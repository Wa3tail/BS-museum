- 踩坑 1：`owner_id NOT NULL DEFAULT auth.uid()` 在 exec_sql 中为 NULL，种子数据必须显式写 `owner_id`；`UPDATE` 在 write 模式下受 RLS 影响，需确保策略允许或用明确 CASE 语句
- 踩坑 2（安全）：本平台匿名请求下 `auth.uid()` 返回字符串 `'anon'`（不是 NULL），`auth.role()` 返回 `'anon'`。因此所有鉴权必须走 `public.caller_uid()`（校验 `auth.role()='authenticated'` 且 uid 不为 'anon'），绝不能只判 `auth.uid() IS NULL`，否则匿名请求可冒充身份提权
